# Simbioz EMS MilTech — лендінг

Статичний лендінг: HTML + CSS + JS без збірки й залежностей.
Контент за `scr/landing_copy_v6.md` та `doc/landing_copy_v6.1.md`, токени за `scr/SIMBIOZ_UI_KIT.md`,
формулювання за `doc/Наскрізні правила для верстки.md`.

## Запуск

```bash
python -m http.server 5173
```

Далі відкрити http://localhost:5173. Через `file://` сторінка не працює: відносні шляхи до CSS, JS і шрифтів не резолвляться.

## Структура

```
index.html          розмітка, вбудований SVG-спрайт іконок
css/styles.css      токени, компоненти, адаптив, темна тема
js/main.js          таби, форма, поява блоків, мобільне меню
fonts/              Sansation + Montserrat, self-hosted, підмножини lat/lat-ext/cyr/cyr-ext
img/                логотипи, favicon
.claude/launch.json конфіг локального сервера
```

## Дизайн-рішення

**Кольори.** Один акцент на всю сторінку — Brand Yellow `#FAB62C`. Оскільки жовтий на білому дає
1,78:1 і не читається, для акценту як **кольору тексту** є окремий токен `--accent-text`
(`#8A6100` на світлому, `#FAB62C` на темному). Синій із UI Kit `#3F7FBF` дає на білому 4,2:1,
тому для тексту посилань затемнений до `#35699E`. Обидва відхилення описані коментарями в CSS.

**Кнопки.** На світлих секціях — темні `#333552` з білим текстом (за UI Kit).
На темних смугах інвертуються: білий фон, темний текст. Жовтий для primary-кнопок не використовується.

**Радіуси.** Зафіксована шкала: кнопки й поля 8px, картки 16px, панелі 24px, пігулки повні.

**Шрифти.** Sansation — заголовки й структурні лейбли. Montserrat — контент і дані.
Підключені локально, `font-display: swap`, розбиті по unicode-range.

**Тема.** Сторінка світла з навмисними темними смугами (hero, розриви, архітектура, форма, футер).
Темна тема системна: `prefers-color-scheme` перевизначає токени, смуги стають ще темнішими,
щоб ритм чергування зберігся.

**Анімація.** Тільки поява блоків при скролі та стани наведення. Реалізовано на IntersectionObserver;
слухачів `window.scroll` немає навмисно. `prefers-reduced-motion` вимикає все.

**Доступність.** Таби з повною ARIA і керуванням стрілками, акордеони на нативному `<details>`,
лейбли над полями, помилки під полями, skip-link. Перевірено: 0 порушень контрасту WCAG AA
у світлій і темній темах при розкритих акордеонах і всіх табах.

## Форма

Форма нікуди не надсилається, поки в `js/main.js` не заданий `FORM_ENDPOINT`.
Поки він порожній, сабміт показує це відкрито замість фальшивого «дякуємо».

```js
var FORM_ENDPOINT = 'https://your-handler.example/lead';
```

Очікує POST із JSON: `name`, `phone`, `email`, `company`, `topic`, `page`.
Валідація, стани завантаження, помилки й успіху вже реалізовані.

## Чого бракує для запуску

Ці пункти взяті з `doc/ТЗ на візуальні матеріали.md`. У розмітці на їх місці стоять
підписані слоти з `<!-- -->` специфікацією — фальшивих інтерфейсів із `<div>` немає.

1. **Зображення hero** — 1600×1200, конструкція, закупівлі, цех і контракт в одному контурі.
2. **Скриншот «Специфікація виробу»** — дерево BOM на 2-3 рівні, ревізія, автор і дата зміни, історія версій.
3. **Скриншот «Дефіцит і аналоги»** — потреба, залишок, дефіцит, дозволені аналоги з пріоритетом.
4. **Скриншот «Контракт і виробництво»** — план-факт за етапами, завантаження потужностей, прогнозна дата.

Вимоги до всіх трьох: мін. 2560px по ширині, світла тема, синтетичні дані з одного набору,
callout'и ①②③ наносяться при верстці.

Окремо: `FORM_ENDPOINT`, реальні контакти у футері, сторінка політики конфіденційності
(зараз `#privacy` — заглушка), лічильник аналітики.
